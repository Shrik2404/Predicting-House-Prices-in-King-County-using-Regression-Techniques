📌 Project Title:
Predicting House Prices in King County using Regression Techniques

📝 Project Description:
This project involves building a predictive model to estimate house prices in King County, Washington. The dataset includes features like the number of bedrooms, bathrooms, square footage, location, and more. The data was cleaned, explored, and used to train regression models to understand the key factors affecting housing prices.

🛠 Tools & Technologies Used:

Python (Pandas, NumPy, Matplotlib, Seaborn)

Scikit-learn

Jupyter Notebook

📊 Machine Learning Techniques Applied:

Linear Regression

Multiple Linear Regression

Polynomial Regression

Pipeline (StandardScaler + PolynomialFeatures + LinearRegression)

Data Cleaning and Imputation (mean substitution for missing values)
